# inkoscribe-website

The marketing website for [inkoscribe](https://github.com/uohzxela/inkoscribe) - a private, local audio transcription tool for macOS.

## About

This is a static website showcasing inkoscribe, a real-time speech-to-text application that transcribes audio without sending data to the cloud. The site provides installation instructions, usage examples, and highlights the privacy-focused approach of the tool.

## Features

- Responsive design optimized for all devices
- Interactive copy-to-clipboard functionality for installation commands
- Clean, accessible typography using Cormorant Garamond and EB Garamond fonts
- Animated elements for enhanced user experience

## Development

This is a simple static HTML website. To view locally:

```bash
# Serve the files using any static server, for example:
python -m http.server 8000
# or
npx serve .
```

Then visit `http://localhost:8000`
